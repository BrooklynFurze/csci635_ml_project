# Title:
Comparison of sentiment analysis techniques using steam reviews

# Abstract:
The goal of this project is to compare different techniques of tokenization when performing sentiment analysis on short texts. The dataset for this will be composed of videogame reviews pulled from Steam, and the value to be predicted will be whether the review is positive or negative. The accuracies of different tokenization methods (both simple and advanced) will be compared and analyzed.

Overall, this project will seek to determine which tokenization values work best for short texts, and to compare simple methods against more advanced ones.
